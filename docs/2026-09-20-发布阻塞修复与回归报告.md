## 设计与兼容性

- 采用订阅名冲突 fail-fast，而不是改名：默认 consumerName 由订阅名派生，保持命名可避免改变 Inbox 幂等身份。不同 exchange 生成同名订阅的配置现在会明确启动失败，不再静默丢绑定；这不是对该配置的自动合并支持。
- 第 2 项的原描述需收窄：修复前 enabled=false 搭配有效显式数值已可使用，失效的是“仅设置 enabled=false”。本次修复自然用法，不放宽次数下限。
- 代理处理采用 Spring AOP 目标类解析而非仅按类名或 ClassUtils 去壳，以覆盖 Spring JDK 动态代理。
- 注册表未新增生命周期冻结要求：保留 register API 可继续注册的既有行为，使用写时复制换取无锁查询。代价为每次注册复制索引，适合启动期写少、发布期读多的用法；未做吞吐基准测试。
- 更严格的一致性校验会使之前静默不一致的配置启动失败；需统一 Builder 与注解声明。
- 不涉及数据库结构、鉴权、外部服务协议或凭据变更。
